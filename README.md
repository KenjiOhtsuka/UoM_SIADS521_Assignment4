# SIADS 521 Assignment 4

This repository contains 4 Jupyter Notebooks:

- fitparse_csv_creation.ipynb
  - Converts `.fit` files into a CSV file and saves it in the `csv_output` directory.
  - The original `.fit` files are only available in the Vocareum environment.
- EDA.ipynb
  - Explores data characteristics, preprocess the dataset, and saves the preprocessed CSV into the `csv_output` directory.
- assignment4.ipynb
  - Final solution, including data analysis and an interactive dashboard.
  - To see the interactive dashboard, it needs to run all code cells because it uses ipywidget.
- dashboard.ipynb
  - Dashboard extracted from assignment4.ipynb for convenience. We can run the dashboard directly without executing the entire original notebook.
